# ✓ Todo List App

A beautiful, fully-featured to-do list application with **local storage functionality**. Add, edit, delete, and manage your tasks efficiently!

## ✨ Features

✅ **Add Tasks** - Quickly add new tasks with a single click or Enter key
✅ **Edit Tasks** - Update task descriptions anytime
✅ **Delete Tasks** - Remove tasks with confirmation
✅ **Mark Complete** - Check off completed tasks
✅ **Filter Tasks** - View All, Active, or Completed tasks
✅ **Local Storage** - All tasks saved automatically in your browser
✅ **Statistics** - See total, active, and completed task counts
✅ **Clear Options** - Remove completed tasks or all tasks at once
✅ **Responsive Design** - Works perfectly on desktop and mobile
✅ **No Backend Needed** - Runs entirely in your browser

## 📖 Step-by-Step Usage Guide

### **Adding a Task**
1. Type your task in the input field
2. Click **"Add"** button or press **Enter**
3. Your task appears in the list

### **Completing a Task**
1. Click the **checkbox** next to the task
2. The task is marked as complete
3. It will appear strikethrough and highlighted

### **Editing a Task**
1. Click the **✎ (Edit)** button on the task
2. A modal window opens with your task text
3. Edit the text
4. Click **"Save"** to update

### **Deleting a Task**
1. Click the **🗑 (Delete)** button
2. Confirm the deletion
3. Task is removed

### **Filtering Tasks**
- **All** - Show all tasks
- **Active** - Show only incomplete tasks
- **Completed** - Show only completed tasks

### **Clear Options**
- **Clear Completed** - Remove all completed tasks at once
- **Clear All** - Remove all tasks (with confirmation)

## 💾 Local Storage

Your tasks are automatically saved to your browser's local storage:
- Tasks persist even after closing the browser
- Data stays on your device (privacy-friendly!)
- No account needed
- No data sent to servers

**Note:** Clearing browser data/cache will delete your tasks. Consider exporting important tasks!
